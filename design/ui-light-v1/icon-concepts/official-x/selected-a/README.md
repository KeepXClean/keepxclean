# KeepXClean 图标 · A 方案

2026-11-10 用户选定：浅绿圆角底配近黑色 X。

## 素材

- `logo.svg`：512 × 512 矢量母版，适用于页面品牌图标、商店素材及大尺寸展示。
- `icon-{size}.png`：16、24、32、48、64、128、256、512、1024 px，RGBA，圆角外透明。
- `logo-small.svg`：16 / 24 px 使用的矢量版。
- `logo-32.svg`、`logo-48.svg`：对应尺寸的矢量版。
- `preview.png`：配色与实际尺寸对照。

## 视觉规范

- 背景：`#EAF6EF`；X：`#172B24`。
- 圆角半径：画布边长的 21.875%。无描边、阴影、渐变或纹理。
- 保留官方 X 的原始路径，仅作等比缩放、居中和填色。
- 常规尺寸的 X 宽度为画布的 56.25%；48 px 为 59.375%；32 px 为 62.5%；16 / 24 px 为 68.75%。小尺寸通过放大整个 X 提高辨识度，不改变笔画几何。
- 不叠加星芒、盾牌或其他角标。功能图标继续使用既有 Lucide 规范。

## 来源与状态

X 路径来自 [X 官方品牌素材](https://about.x.com/en/who-we-are/brand-toolkit)，原件保留于上级目录 `logo.svg` 和 `x-logo-original.zip`。

原始 A 方案由内置 imagegen 生成，见 `../a-mint.png`；完整生成提示词见 `../prompts.json`。本目录使用原始 SVG 路径精确排版，并通过 Sharp 导出 PNG，没有重新生成或描摹 X 的轮廓。

本目录保留早期 A 方向的平面版素材；当前实现采用 `../selected-black-titanium/` 中的无保护圈黑钛版，以该目录和项目 AGENTS.md 为准。
