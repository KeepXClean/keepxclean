## 数据与恢复

- 继续使用原 `kxc_filter_config_v1`，首次升级把原值保存到 `kxc_pre_ui_config_backup`。旧 v1 缺失字段按默认值补齐；损坏或高版本配置不被静默覆盖。
- 统计迁移到 `kxc_stats_v2`，保留累计，不把无法确定日期的旧“今日”数字当作当前日；升级当天显示统计范围提示。
- 最近 200 条可见日志与最多 10,000 个推文 ID 去重记录独立保存。清空日志保留统计和去重记录；这是有限窗口去重，不承诺永久识别无限历史推文。
- 配置重置保留黑白名单、日志和统计；JSON 替换有配置摘要冲突校验，不重放历史外部操作。
- 快照刷新失败继续使用最后可用缓存；初次离线使用内置词库。自定义服务未经授权不会保存，也不会向备用提供方发送用户数据。
- 待执行动作持久化，扩展恢复后继续 pending；正在运行但缺少回执的外部动作标记 unknown。已完成收据保留最近 100 条 / 7 天，待执行或运行中记录不因这个上限被丢弃。
- 导入中断时保留已经保存的本地账号，不自动重放不确定外部动作。任务取消不宣称回滚已经完成的外部批次。
- 降级或回退前应停止未执行外部任务并导出配置；回退不会取消已经成功的 X 或社区操作。

## 尚未验证的范围

1. Ego 当前控制接口不提供 `Extensions.loadUnpacked`，实际调用返回 `Method not available`。因此没有将真实 MV3 包加载进 Ego 验证工具栏弹窗、内容脚本权限或可选站点权限弹窗；本地宿主不能作为这部分成功证据。
2. 没有对真实 X 账号执行原生拉黑或读取黑名单联调。X 当前接口字段、CSRF / Bearer 要求、真实 SPA DOM、账号切换与多标签页隔离需使用明确测试账号继续验证。代码已有 UID 绑定、超时、回执校验和失败状态。
3. 生产社区 API / CDN、线上 D1 与 R2 未联调或部署。客户端提交者资料仍是自报数据，不是服务端认证过的身份。
4. 全量读屏器检查、浏览器 200% 缩放和真实扩展离线冷启动未完成。已实现焦点、状态语义、reduced-motion 与响应式样式；不能把实现等同于完整无障碍认证。
