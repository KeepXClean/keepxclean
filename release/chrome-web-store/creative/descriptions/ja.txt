KeepXClean は、X（Twitter）のタイムライン、検索結果、返信から不要な内容を減らす無料のオープンソース拡張機能です。

主な機能

• 読みたい投稿に、もっと集中。
スパム返信、同一スレッドのコピペ連投、なりすまし、広告をフィルター。公式 @grok の返信を標準保護しつつ短文呼び出しの任意除外や、「おすすめ」「フォロー中」ごとの動作設定にも対応します。

• タイムラインのルールは、自分で。
10 言語パブリックキーワードパック（全 45 ルール）、外部リンクのドメインフィルター、独自キーワードと正規表現に加え、オフライン共有可能な .kxc-pack.json ルールパックに対応。

• ノイズを畳んで、文脈は残す。
不要な投稿を折り畳み、理由を確認。展開して該当ルールの調整画面へ直接移動したり、一致項目をワンクリックで無効化できるほか、ルール別統計とローカル戦績レポート PNG 出力も利用できます。

• 信頼する人の投稿を大切に。
永続的なアカウント ID で許可・ブロックリストを管理。クイックスタートカードやアカウント画面から X の既存ブロックリストも取り込めます。

• ローカル処理。選択は明確に。
10 言語とライト・ダークテーマ、ローカル完結の解析ヘルス自己チェックを搭載。任意の chrome.storage.sync デバイス間設定同期、X ブロック同期、コミュニティ報告はいずれも初期状態でオフです。

ローカル優先とプライバシー

KeepXClean はパスワードや DM を要求しません。アカウント識別とユーザーが実行する X 操作のため、X の Cookie を端末内で読み取ります。セッション Cookie と Web クライアントの認証値は X との通信にのみ使用し、KeepXClean サーバーには送信しません。任意のコミュニティ報告についてはプライバシーポリシーをご覧ください。

任意の報告には対象アカウントの公開情報、理由、報告者の SHA-256 派生 ID とアカウント経過日数が含まれます。X のセッション Cookie や認証値は KeepXClean サーバーに送信しません。任意の chrome.storage.sync（初期オフ）はフィルタ設定とルールのみを同期し、ローカルの許可・ブロックリストや履歴は端末内に留まります。解析ヘルスチェックは端末内のみで完結し、テレメトリは送信しません。
