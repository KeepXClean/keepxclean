KeepXClean は、X（Twitter）のタイムライン、検索結果、返信から不要な内容を減らす無料のオープンソース拡張機能です。

主な機能

• 読みたい投稿に、もっと集中。
スパム返信、なりすまし、広告をフィルター。3 段階から好みの強度を選べます。

• タイムラインのルールは、自分で。
24 の公開キーワードルールに加え、独自キーワードと正規表現で細かく設定。

• ノイズを畳んで、文脈は残す。
不要な投稿を折り畳み、理由を確認。読みたいときは、いつでも展開できます。

• 信頼する人の投稿を大切に。
永続的なアカウント ID で許可・ブロックリストを管理。X の既存リストも取り込み。

• ローカル処理。選択は明確に。
10 言語とライト・ダークテーマ。X ブロック同期とコミュニティ報告は任意です。

ローカル優先とプライバシー

KeepXClean はパスワードや DM を要求しません。アカウント識別とユーザーが実行する X 操作のため、X の Cookie を端末内で読み取ります。セッション Cookie と Web クライアントの認証値は X との通信にのみ使用し、KeepXClean サーバーには送信しません。任意のコミュニティ報告についてはプライバシーポリシーをご覧ください。

任意の報告には対象アカウントの公開情報、理由、報告者の SHA-256 派生 ID とアカウント経過日数が含まれます。X のセッション Cookie や認証値は KeepXClean サーバーに送信しません。

KeepXClean は独立したプロジェクトです。X Corp. との提携関係はなく、同社による承認や提供を受けていません。
