KeepXClean은 X(트위터)의 타임라인, 검색 결과, 답글에서 원치 않는 콘텐츠를 줄이는 무료 오픈소스 브라우저 확장 프로그램입니다.

주요 기능

• 읽을 가치가 있는 게시물에 집중하세요
스팸 답글, 사칭 계정, 광고를 필터링하세요. 세 가지 강도 중 원하는 설정으로 시작하세요.

• 내 피드의 규칙은 내가 정해요
공개 키워드 규칙 24개와 사용자 키워드, 정규식으로 필터링 대상을 직접 선택하세요.

• 잡음은 접고, 맥락은 남겨요
원치 않는 게시물을 접고 필터링 이유를 확인하세요. 원문은 언제든 펼칠 수 있어요.

• 믿고 읽는 사람들의 글은 그대로
영구 계정 ID로 차단·허용 목록을 관리하고 기존 X 차단 목록도 가져오세요.

• 로컬 필터링, 명확한 선택
10개 언어와 밝은·어두운 테마를 지원해요. X 차단 동기화와 커뮤니티 신고는 선택 사항이에요.

로컬 우선 처리와 개인정보

KeepXClean은 비밀번호나 DM을 요청하지 않습니다. 계정 식별과 사용자가 실행한 X 작업을 위해 X 쿠키를 로컬에서 읽습니다. 세션 쿠키와 웹 클라이언트 인증 값은 X와의 통신에만 사용하며 KeepXClean 서버로 전송하지 않습니다. 선택적 커뮤니티 신고 데이터는 개인정보 처리방침을 참고하세요.

선택적 신고에는 대상 계정의 공개 정보와 사유, 신고자의 SHA-256 파생 식별자와 계정 나이가 포함됩니다. X 세션 쿠키와 인증 값은 KeepXClean 서버로 전송하지 않습니다.

KeepXClean은 독립 프로젝트입니다. X Corp.와 제휴 관계가 없으며 X Corp.의 승인이나 제작을 받은 제품이 아닙니다.
