KeepXClean은 X(트위터)의 타임라인, 검색 결과, 답글에서 원치 않는 콘텐츠를 줄이는 무료 오픈소스 브라우저 확장 프로그램입니다.

주요 기능

• 읽을 가치가 있는 게시물에 집중하세요
스팸 답글, 동일 스레드 복붙 도배, 사칭 계정, 광고를 필터링하세요. 공식 @grok 답글은 기본 보호하면서 짧은 @grok 호출을 선택 필터링하고 추천·팔로잉 장면별 동작을 설정할 수 있어요.

• 내 피드의 규칙은 내가 정해요
10개 언어 공용 키워드 팩(기본 45개 규칙), 외부 링크 도메인 필터, 사용자 키워드·정규식은 물론 오프라인 공유용 .kxc-pack.json 규칙 팩을 지원해요.

• 잡음은 접고, 맥락은 남겨요
원치 않는 게시물을 접고 이유를 확인하세요. 펼친 상태에서 해당 규칙 조정 화면으로 바로 이동하거나 일치 항목을 원클릭 비활성화하고, 규칙별 통계와 로컬 리포트 PNG도 저장할 수 있어요.

• 믿고 읽는 사람들의 글은 그대로
영구 계정 ID로 차단·허용 목록을 관리하고, 빠른 시작 카드나 계정 화면에서 기존 X 차단 목록을 바로 가져오세요.

• 로컬 필터링, 명확한 선택
10개 언어, 밝은·어두운 테마, 로컬 전용 파싱 상태 자가 진단을 지원해요. 선택적 chrome.storage.sync 기기 간 설정 동기화, X 차단 동기화, 커뮤니티 신고는 모두 기본적으로 꺼져 있어요.

로컬 우선 처리와 개인정보

KeepXClean은 비밀번호나 DM을 요청하지 않습니다. 계정 식별과 사용자가 실행한 X 작업을 위해 X 쿠키를 로컬에서 읽습니다. 세션 쿠키와 웹 클라이언트 인증 값은 X와의 통신에만 사용하며 KeepXClean 서버로 전송하지 않습니다. 선택적 커뮤니티 신고 데이터는 개인정보 처리방침을 참고하세요.

선택적 신고에는 대상 계정의 공개 정보와 사유, 신고자의 SHA-256 파생 식별자와 계정 나이가 포함됩니다. X 세션 쿠키와 인증 값은 KeepXClean 서버로 전송하지 않습니다. 선택적 chrome.storage.sync(기본 꺼짐)는 필터 규칙과 설정만 동기화하며 로컬 차단·허용 목록과 기록은 기기에만 남습니다. 파싱 자가 진단은 로컬에서만 동작하며 원격 텔레메트리를 전송하지 않습니다.

KeepXClean은 독립 프로젝트입니다. X Corp.와 제휴 관계가 없으며 X Corp.의 승인이나 제작을 받은 제품이 아닙니다.
